To publish on GitHub Pages:
1. Put index.html in the root of renyu2002.github.io.
2. Create an assets/ folder in the same root.
3. Upload the placeholder SVGs first so the page renders cleanly.
4. Replace placeholders with real assets as they become available.
5. Add assets/deformation_demo.mp4 when the demo is ready.
6. Add assets/Yu_Ren_CV.pdf when the CV is ready.
